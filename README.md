# WeekFlow – Haftalık Program Takip Uygulaması

WeekFlow, derslerini ve günlük planlarını haftalık olarak düzenleyip takip edebileceğin bir uygulamadır.

## Özellikler

- Haftalık programını oluştur ve düzenle.
- Bugünün programını hızlıca görüntüle.
- Programını kaydet ve daha sonra kaldığın yerden devam et.

## Platformlar

- Windows (PC)
- Android
- iOS (iPhone)
